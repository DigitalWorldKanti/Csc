# Shadow Assassin 3D

A browser-playable 3D stealth-action prototype. It uses Three.js from jsDelivr, so an internet connection is required while playing.

## Play
Open the GitHub Pages URL for this folder if Pages is enabled, or serve this folder locally:
1. Download this folder.
2. Run `python -m http.server 8000` from inside it.
3. Open `http://localhost:8000`.

## Controls
- WASD: move
- Mouse drag: rotate camera
- E: silent takedown (approach from behind)
- Space: close-range attack
- Shift: sneak
- Mobile: on-screen directional/action controls

## Prototype
Includes a 3D arena, guards, vision-cone alerts, health, takedowns, collectibles, extraction, and a simple next-level loop. This is an early playable prototype rather than a finished commercial game.
